# Nintendo 3DS Custom Theme Guide

A technical guide documenting the workflow I used to create, troubleshoot,
package, transfer, and test custom Nintendo 3DS themes using macOS and real
Nintendo 3DS hardware.

I wrote this documentation after working through the process myself, including
image preparation, theme configuration, audio conversion and looping, package
creation, wireless file transfer, hardware testing, and troubleshooting.
